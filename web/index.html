Honesty

"New" means the statement text is not found verbatim in Mathlib and has not been minted before. That is all. The lemmas are small: arithmetic, finite sums, small inequalities, binomial coefficients. The value is a machine-checked proof and your name on it. We claim no mathematical importance, and Lean, not a language model, decides validity.

Precedent: TheoryMine (Edinburgh, 2010) sold naming rights to machine-proved theorems. What differs here: Lean 4 + Mathlib checking, an open registry, signed attestations, CC0 lemma texts.

Verify any certificate

You do not need to trust us. Each registry entry has a Lean file and a signed attestation (DSSE, in-toto). To check one yourself:

python tools/attest_verify.py bat-XXXXXXXXXXXX.dsse.json --key <pubkey> --expect-keyid <pinned keyid> --check-subjects .

That checks the signature and that the Lean file matches the signed hash. Then re-run Lean on the file yourself:

lake env lean bat-XXXXXXXXXXXX.lean

Full verify (needs a local Lean 4 + Mathlib project; see README): python -m buyatheorem verify bat-XXXXXXXXXXXX. The attestation's predicate type is not yet in the verifier's list, so a valid signature currently returns exit code 5 ("signature valid, predicate type unknown"), not 0.
